3DGS/NeRF 重建

Real → 3DGS 场景资产

📸

核心问题

如何从多视角 RGB 图像重建高质量 3D 场景？

传统 SLAM 建图依赖结构化场景且耗时，3DGS 通过可微分高斯渲染实现高质量自由视角合成。NeRF 系列虽质量高但速度慢，3DGS 在速度和质量间取得平衡。

项目 开源/闭源 年份 输入 核心能力
3D Gaussian Splatting (Inria) ✅ 开源 2023 多视角 RGB + COLMAP 可微分高斯渲染，实时渲染，高质量 3D 重建
InstantSplat (NVIDIA) ✅ 开源 2024 少量视角 RGB 稀疏视角初始化，快速收敛，few-shot 3DGS
Nerfstudio ✅ 开源 2023+ 多视角 RGB 统一 NeRF/3DGS 框架，支持多种变体
COLMAP ✅ 开源 2010+ 多视角 RGB SfM 稀疏重建 + MVS 稠密重建
Feature Splatting ✅ 开源 2024 多视角 RGB 语义特征嵌入 3DGS，支持开放词汇查询
Gaussian Grouping ✅ 开源 2024 多视角 RGB 逐高斯语义分组，无需分割模型
Segment Anything in 3D Gaussian ✅ 开源 2024 3DGS + 文本/框/点 在 3DGS 空间直接分割，无需逐帧标注
💡 关键洞察：3DGS 已成为 Real2Sim 的主流重建格式，速度快（实时渲染）、质量高（接近 NeRF）、支持语义嵌入（特征高斯）。NVIDIA InstantSplat 专门为机器人场景优化。

场景分割 + 物理属性推断

3DGS → 可交互资产

🧠

核心问题

如何从 3DGS 场景中分离物体并推断物理属性？

3DGS 重建的是整个场景的静态表示，但机器人需要与独立物体交互。需要分割出单个物体，并推断其质量、摩擦、关节类型等物理属性。

项目 开源/闭源 年份 核心能力
SAM 2 (Meta) ✅ 开源 2024 零样本视频/图像分割，通用性强
SAMpro3D ✅ 开源 2025 零样本 3D 分割 + 增强投影，支持铰接物体
GroundingDINO ✅ 开源 2024 语言引导目标检测，开放词汇
Assist-GS ✅ 开源 2025 分解式 3DGS 重建，层次化实例/部件分割
RoboSimGS MLLM 物理推断 ✅ 开源 2025 多模态 LLM 推断密度、刚度、摩擦、铰接类型
ArtiTwinSplat ✅ 开源 2026 无监督铰接发现 + URDF 生成，无需 CAD
URDFormer ✅ 开源 2024 单张图 → URDF 生成，支持铰接物体
RoboGS ✅ 开源 2025 语义高斯分割 + 部件级物理属性推断
🎯 技术路线对比：
MLLM 推断路线（RoboSimGS）：通用但依赖 LLM 质量
监督学习路线（RoboGS）：需要高质量标注数据
几何启发路线（ArtiTwinSplat）：无需标注但受限于铰接结构

Isaac Lab 资产导入

URDF/USD → 仿真环境

📦

核心问题

如何将 3D 资产转换为 Isaac Lab 可用的仿真环境？

Isaac Lab 使用 OpenUSD 格式构建场景，支持 URDF 和 MJCF 导入。URDF 适合描述机器人（连杆+关节），MJCF 适合物理仿真，USD 适合场景渲染和组合。

项目 开源/闭源 格式转换 核心能力
Isaac Sim URDF Importer 🔒 NVIDIA 官方 URDF → USD 图形界面拖拽导入，自动物理材质映射
Isaac Lab convert_urdf.py ✅ 开源 URDF → USD 命令行批量转换，支持 ROS 2 资产
Isaac Lab MJCF Importer 🔒 NVIDIA 官方 MJCF → USD MuJoCo XML 导入，支持丰富接触模型
GSDF (GSWorld) ✅ 开源 3DGS + URDF → GSDF 高斯渲染 + 物理仿真资产融合格式
GS-Playground ✅ 开源 3DGS → Isaac Lab 批量 3DGS 场景导入，支持并行仿真
RoboTwin 2.0 资产 ✅ 开源 URDF + USD 120+ 模型库，52 种纹理，生成式双胞胎资产
💡 关键洞察：Isaac Lab 的资产管道是 URDF/MJCF → USD。3DGS 本身不是仿真格式，需要通过 GSDF 或 mesh 提取后转换为 USD 才能导入 Isaac Lab。GSWorld 的 GSDF 格式是目前最接近"3DGS 直接进 Isaac Lab"的方案。

RL / IL / World Model 训练

仿真环境 → 策略模型

🎯

核心问题

如何在仿真环境中高效生成训练数据并训练策略？

这是 AutoDataGen 的核心领域。数据生成方法从模仿学习（需要示教）到强化学习（自动探索）再到世界模型（预测性训练）演进。Isaac Lab 提供 GPU 并行仿真，大幅提升数据生成效率。

项目 开源/闭源 年份 类型 核心能力
Isaac Lab RL ✅ 开源 2024+ RL GPU 并行强化学习，集成 PPO/SAC/DDPG
RoboTwin 2.0 ✅ 开源 2025+ IL + 基准 生成式数字双胞胎，双臂操作，50 个基准任务
InternDataEngine ✅ 开源 2026 数据生成 Isaac Sim 大规模数据引擎，630K+ 轨迹，5 万任务
SoftMimicGen ✅ 开源 2026 IL 数据 可变形物体数据生成，软体操作
AutoDataGen ✅ 开源 2026 IL 数据 LLM 分解 + 原子技能 + cuRobo 运动规划
MimicGen ✅ 开源 2023 IL 数据 示教变换，从少量示教生成大规模数据
LeRobot (HuggingFace) ✅ 开源 2024+ IL 框架 统一 IL 训练框架，支持 ACT/Diffusion Policy
robomimic ✅ 开源 2022+ IL 框架 BC/IL 策略训练，RoboMimic 基准
Diffusion Policy ✅ 开源 2023 IL 策略 扩散模型生成动作序列，多模态动作分布
ACT (Aloha) ✅ 开源 2024 IL 策略 动作分块 Transformer，双臂协调

📊 数据生成方法对比

  • MimicGen 系列：需要少量示教 → 变换生成（轨迹级）
  • AutoDataGen：零示教 → LLM 分解 + 运动规划（技能级）
  • InternDataEngine：零示教 → LLM 任务定义 + Isaac Sim（大规模）
  • RoboTwin 2.0：生成式双胞胎 → 动作数据（双臂专用）

⚡ 效率对比

  • MimicGen：1 条示教 → ~1K-10K 轨迹
  • AutoDataGen：1 个任务描述 → ~10-100 轨迹
  • InternDataEngine：5 万任务 → 630K+ 轨迹（最大规模）
  • RoboTwin 2.0：50 个任务 → ~1K 轨迹/任务

测试部署

策略模型 → 真实机器人

🚀

核心问题

如何将仿真训练的策略可靠地部署到真实机器人？

Sim2Real 迁移是 R2S2R 的最后一步，也是最关键的一步。视觉 gap（渲染 vs 真实）和动力学 gap（仿真物理 vs 真实物理）是主要挑战。

项目 开源/闭源 年份 核心能力
Isaac Sim SIL/HIL 🔒 NVIDIA 官方 2024+ 软件/硬件在环测试，数字孪生同步
ROS 2 + MoveIt 2 ✅ 开源 2024+ 真实机器人部署标准栈，运动规划 + 控制
real-is-sim ✅ 开源 2025 动态数字孪生 60Hz 同步，降低 sim2real gap
ExoGS CmdExo ✅ 开源 2026 外骨骼采集 → 3DGS → 策略 → 真实部署
RoboTwin 2.0 sim2real ✅ 开源 2025+ 生成式双胞胎 + 物理一致性验证 + 真实部署
💡 关键洞察：Sim2Real 的核心挑战是 视觉 gap + 物理 gap + 动态 gap。3DGS 通过照片级真实感渲染缩小视觉 gap，但物理参数（摩擦、阻尼）的准确性仍然依赖人工调参或 LLM 推断。real-is-sim 的动态数字孪生思路（60Hz 真实→仿真同步）是解决 gap 的新方向。

🗺️ 技术路线总结

路线 A：3DGS 直接进 Isaac

  • 核心：GSDF 格式（GSWorld）
  • 优势：端到端，保留 3DGS 渲染质量
  • 劣势：GSDF 还在早期，生态不成熟
  • 代表：GSWorld, RoboSimGS, Re3Sim

路线 B：3DGS → Mesh → URDF → USD

  • 核心：传统资产管线
  • 优势：成熟，Isaac Lab 原生支持
  • 劣势：信息丢失，mesh 质量依赖提取
  • 代表：Real2Render2Real, DISCOVERSE

路线 C：生成式资产

  • 核心：LLM/扩散模型直接生成资产
  • 优势：无需真实场景，无限扩展
  • 劣势：物理真实性难以保证
  • 代表：URDFormer, RoboGen, RoboTwin 2.0
🔑 AutoDataGen 的扩展方向：
短期：在阶段 ④ 深化——支持更多技能类型、优化 LLM 分解质量、集成更多运动规划器
中期：向阶段 ③ 扩展——支持从 URDF/USD 直接加载环境，减少手动配置
长期：向阶段 ①② 扩展——集成 3DGS 重建 + 物理推断，实现真正的端到端 R2S2R 数据生成
