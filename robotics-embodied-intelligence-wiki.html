1. 机体：主流厂商与型号

机体不只是承载算法的外壳。自由度、传动、传感、末端执行器、实时接口和安全边界共同决定了可学习动作空间。比较机器人之前，应先按形态和用途分组。

边界：本章描述物理平台和公开接口，不把演示视频中的能力直接视为可复现产品能力，也不把某个平台配套的数据集或策略模型等同于硬件本身。

形态分类

  • 固定机械臂：工作空间受基座限制，但控制接口成熟，适合操作、力控和数据采集。
  • 移动操作机器人：把导航与机械臂工作空间合并，任务编排和状态估计更复杂。
  • 四足平台：以通过性和动态平衡为核心，可外挂机械臂形成移动操作系统。
  • 全尺寸人形：面向人类环境和双足全身操作，接触切换、功耗和安全是主要约束。
  • 紧凑型或开放研究人形：成本和开发接口优先，常用于 RL、足球和具身模型验证。

2. 控制

控制研究如何根据参考目标和反馈，让物理系统产生期望行为。机械臂动力学常写成：

M(q) qdd + C(q, qd) qd + g(q) + tau_f = tau + J(q)^T f_ext

其中 q 是关节位置，M 是惯性矩阵，C 是科氏与离心项，g 是重力项，tau 是驱动力矩，f_ext 是外部接触力。

边界：估计器回答“当前状态是什么”，规划器回答“应走哪条轨迹”，控制器回答“如何稳定跟踪并响应扰动”，策略回答“给定观测应采取什么动作”，任务编排负责跨技能调度。

典型层级

  1. 驱动层：电流、力矩和电机换相。
  2. 关节伺服：位置、速度、力矩闭环与前馈补偿。
  3. 任务空间或全身控制：末端位姿、力、质心、接触和多任务约束。
  4. 技能或策略：生成参考轨迹、目标位姿或动作块。
  5. 任务编排：选择技能、检查前置条件、监控和恢复。

接口检查

  • 被控对象、状态、观测和参考量
  • 控制频率、延迟与抖动
  • 动作是力矩、关节目标还是末端增量
  • 模型、估计器与坐标系依赖
  • 接触、饱和、限位和安全监督
  • 稳定性、鲁棒性和可复现实验条件

基础入口：Murray、Li、Sastry 的几何与控制教材[4]，以及现代机器人学中的动力学与控制章节。

3. 运动学与 IK

机器人运动学用几何关系描述关节变量与连杆位姿、速度和加速度的映射，不直接处理质量、惯性和力。正运动学从关节配置得到末端位姿，逆运动学从目标位姿寻找关节配置。[1][2]

T_0^n(q) = T_0^1(q_1) ... T_(n-1)^n(q_n) ; xdot = J(q) qdot

对象与表示

  • 构型空间 C-space：所有合法配置形成的空间，关节限位和闭链约束定义其可行子集。
  • SO(3) 与 SE(3)：分别表示三维旋转和刚体位姿；DH 参数与指数积是两类常见链式表示。[4]
  • Jacobian：把关节速度映射到任务空间速度，也通过虚功关系连接末端力与关节力矩。[1]

4. 传统控制方法

传统机器人栈不仅包含反馈控制器，也包含碰撞检测、路径规划、轨迹优化、时间参数化和轨迹执行。规划器决定如何从当前状态到达目标，控制器负责在扰动和模型误差下跟踪这条轨迹；两者通过状态估计、约束和安全监督闭环。

边界：MoveIt 和 cuRobo 是运动生成与集成框架，不是单一规划算法，也不是电机力矩控制器。它们输出路径、带时间轨迹或滚动时域动作，再交给 Servo、MPC、关节轨迹控制器、阻抗控制器或驱动层执行。

从目标到执行的结构

  1. 机器人与世界状态：从 URDF / SRDF、关节状态、附着物和环境几何建立 RobotModel、PlanningScene 或 GPU world model。
  2. 运动学与碰撞：计算 FK、IK、Jacobian、自碰撞和机器人与环境的离散或连续碰撞。
  3. 全局几何规划：在构型空间搜索无碰路径，解决狭窄通道、障碍绕行和不同 IK 分支。
  4. 轨迹优化与时间参数化：平滑路径，并满足速度、加速度、jerk、碰撞距离和任务空间目标。
  5. 轨迹执行：校验起点和约束，把带时间关节轨迹发送给 ros2_control 或厂商控制器，并监控偏差与取消。
  6. 在线闭环：MoveIt Servo、MPC 或局部优化器根据新目标和障碍滚动更新命令，底层伺服以更高频率执行。

5. RL 运动控制

强化学习从 Bellman 的最优性原理出发：一个序贯决策问题的最优剩余策略，只依赖当前状态及其后的最优子问题。机器人运动控制把动力学和接触写成 MDP 或 POMDP，并学习策略 pi(a_t | o_<=t) 最大化长期回报，而不是只优化当前一步。[50][51]

Bellman 方程是起点

MDP 可写成 (S, A, P, r, gamma)：状态 s、动作 a、转移分布 P、奖励 r 和折扣因子 gamma。回报、策略价值和最优动作价值满足递推关系：

G_t = sum_(k=0)^inf gamma^k r_(t+k) ; V^pi(s) = E_pi[r + gamma V^pi(s')] ; Q*(s,a) = E[r + gamma max_(a') Q*(s',a')]
  • Bellman 期望方程：固定策略后，当前价值等于一步奖励加下一状态价值的期望，可用迭代策略评估或采样估计。
  • Bellman 最优性方程：在每一步选择后续价值最大的动作，导出 value iteration、Q-learning 和最优控制中的动态规划。
  • POMDP：实机不能直接读取完整状态，策略需根据噪声观测、历史、RNN / Transformer 隐状态或显式估计器形成 belief。
  • 连续机器人控制：高维连续动作使逐动作取 max 困难，因此步态控制更常直接优化参数化策略并用 critic 估计价值。

与传统步态控制的边界：ZMP / LIPM、CPG、足步规划、质心 MPC、全身 QP 和混合零动态可以独立构成模型式步态控制器。RL 可以替代其中某层、学习残差或调参，也可以端到端输出动作；“用了 RL”不代表系统没有模型、参考轨迹或 PD / MPC。

步态策略实际控制什么

  1. 命令与观测：目标线速度、角速度、步态参数，加上机身姿态与速度、关节状态、历史动作、接触和可选地形感知。
  2. 策略动作：最常见是关节位置目标或参考残差，也可输出关节速度、力矩、足端目标、落足点或 MPC / WBC 的参数。
  3. 执行接口：策略通常以 20-200 Hz 更新，PD、阻抗或力矩伺服以更高频率执行；动作缩放、滤波、限位和延迟属于策略定义的一部分。
  4. 奖励与终止：命令跟踪、姿态、足端接触、能耗、平滑、冲击和存活共同塑造步态；奖励不是客观真理，而是设计的最优性标准。

步态学习的成熟流派

下列路线可以叠加，并非互斥。当前四足和人形系统常用 PPO 作为优化器，真正区分流派的是参考来源、策略接口、训练信息和部署时的适应机制。[54]

流派结构与代表方法获得的能力主要代价
参数化步态 / gait-boundCPG、相位变量、预定义摆动轨迹或有限状态机给出步态骨架，RL 调频率、落足、增益或残差步态可控、易加入先验、样本需求较低动作空间受模板限制，跨形态和非周期技能扩展困难
无参考命令跟踪 / gait-free以目标速度和转向为命令，PPO 从奖励中学习关节目标；并行仿真、课程和地形随机化已形成标准配方[55]步态可自行涌现，可统一站立、行走、转向和恢复奖励工程量大，可能产生不自然或利用仿真漏洞的动作
参考运动模仿DeepMimic 用姿态、速度、末端和质心误差构造模仿奖励，并与任务奖励结合[9]自然动作、特技和指定风格依赖动作捕捉、重定向、相位和参考覆盖
对抗式运动先验AMP 用判别器从演示学习风格奖励，不要求逐帧跟踪单一参考[56]兼顾动作自然性、任务自由度和多技能判别器稳定性、数据偏差与风格奖励权重需要调节
特权教师与非对称 Actor-Critic训练期 critic 或 teacher 读取地形、接触、摩擦等真值，student 仅用实机可得本体感知和历史[57]复杂地形学习更快，并把不可部署信息蒸馏到策略教师信息未必能由部署观测辨识，蒸馏会产生信息缺口
系统辨识、随机化与零样本迁移执行器网络或标定模型配合质量、摩擦、延迟、噪声、外扰和地形随机化[10]从仿真直接部署到真实四足或人形随机化过宽会保守，过窄会失配；硬件安全壳仍不可省略
在线隐式适应RMA 用特权环境编码训练基础策略，再由近期状态动作历史估计低维 extrinsics[11]适应载荷、摩擦、损伤和未知地形历史中不可观测的因素无法可靠恢复，估计误差会传给策略
分层与模型混合高层足步 / 速度 / 地形规划加低层 RL，或 MPC / WBC 生成参考、RL 学残差和接触反馈兼顾长时规划、显式约束和学习鲁棒性层间接口、时标、参考可行性和训练分布必须共同设计
人形全身统一控制动作重定向或特权 teacher 生成全身参考，策略联合控制腿、躯干和手臂，并用历史网络适应 POMDP[58]自然摆臂、抗扰、负载行走和 loco-manipulation 基础高维接触、跌倒成本、数据重定向和硬件安全最困难

典型训练到部署管线

  1. 在并行物理仿真中建立机体、执行器、延迟与接触模型。
  2. 教师策略使用仿真特权状态，或用参考动作提供模仿目标。
  3. 随机化质量、摩擦、延迟、地形、传感噪声和外扰，缩小 sim-to-real 差距。[10]
  4. 学生策略仅使用实机可得观测，通过历史编码或适应模块估计隐变量。
  5. 实机以固定周期输出关节目标或力矩，底层伺服完成高频跟踪。
  6. 安全监控处理跌倒、过热、越界、通信丢失和恢复姿态。

论文复现必须比较

  • MDP / POMDP 定义、状态与观测历史
  • Bellman 目标、GAE、bootstrap 和 horizon
  • on-policy / off-policy 与样本预算
  • 力矩、关节目标或残差动作
  • 奖励各项、尺度、课程和终止
  • 随机化分布与实机辨识范围
  • 策略频率和底层伺服频率
  • 参考动作来源、相位与重定向
  • teacher / critic 的特权信息
  • 安全壳、恢复、能耗和硬件磨损

6. VLA

Vision-Language-Action 模型接收视觉观测、语言指令和可选机器人状态，直接生成可执行动作或动作块，可抽象为 pi(a_t:t+H | o_<=t, l)。[3]

边界：只输出文本计划的 VLM 不是低层 VLA；语言条件行为克隆可以是 VLA 的前身；VLA 输出仍通常由插值、IK、阻抗或关节伺服转换为安全的硬件命令。

关键设计轴

  • 动作表示：离散动作 token、连续回归、扩散或 flow matching 动作块。
  • 时间结构：单步动作、固定 horizon action chunk、分层语义子任务加低层动作。
  • 数据范围：单平台、跨任务、跨机构或混合网页视觉语言数据。
  • 适配方式：从头训练、VLM 共训练、全量微调、LoRA 或动作专家适配。

代表性路线

工作年份骨架贡献动作 / 开放性

RT-22023把 VLM 与机器人轨迹共微调，并明确使用 VLA 名称[13]动作表示为文本 token

评测时记录

  • 训练数据的平台、任务与许可
  • 视觉和语言预训练来源
  • 动作定义、归一化和 chunk horizon
  • 闭环频率与端到端延迟
  • 新物体、新场景、新任务和新机体拆分
  • 失败恢复、人工接管和安全接口

7. WAM

World Action Model 是 2025-2026 年快速形成的标签，用于描述把未来状态预测与动作生成耦合起来的具身模型。它尚不是历史稳定、边界完全统一的术语。2026 年综述把 WAM 组织为级联式与联合式两大类。[19]

术语提醒：WAM 在其他机器人文献中也可能指 Whole-Arm Manipulation。本文只在本章使用 World Action Model，引用时必须写出全称。

World model: p(o' | o, a) ; VLA: p(a | o, l) ; WAM: p(o', a | o, l)

谱系与结构

  • 模型式控制与 Dyna：学习或使用转移模型，在内部 rollout 中评估动作。
  • 潜变量世界模型：World Models、PlaNet、Dreamer 等在紧凑状态中预测并学习策略。
  • 动作条件视频模型：预测动作造成的图像或视频变化，可作为规划、数据生成或评测器。
  • 级联 WAM：先生成像素、几何或潜变量未来，再由逆动力学或动作解码器恢复动作。
  • 联合 WAM：共享模型同时生成未来表示与动作，使世界预测直接参与策略训练。

不能只看生成视频

  • 真实任务成功率与闭环稳定性
  • 未来视觉保真度
  • 接触、遮挡和物体恒常性的物理一致性
  • 从预测未来恢复动作的可辨识性
  • 规划跨度、滚动重规划与误差累积
  • 视频生成和动作输出的闭环延迟

近期 WAM 论文大量仍是预印本。骨架应按预测载体、耦合方式、训练目标和测试时是否显式想象来组织，而不是按模型名称堆列表。[19]

8. 数据与采集

具身数据是带时间结构的交互记录。最小单位通常是 episode，其中每个 step 对齐观测、状态、动作、时间戳和可选奖励、语言、成功或失败标签。数据质量首先是控制与测量问题，其次才是文件格式问题。

采集方式

  • 示教：拖动示教和 kinesthetic teaching，直观但受机体可回驱性限制。
  • 遥操作：手柄、VR、动捕和 leader-follower；ALOHA 支持双臂采集。[20]
  • 自主 rollout：现有策略执行，人在失败前后干预，可采集恢复和负样本。
  • 仿真与合成：脚本、规划器、策略或生成模型产生轨迹，需记录随机化和 sim-to-real 偏差。
  • 人类视频：规模大但缺少机器人动作和精确状态，需要姿态、潜动作或逆动力学桥接。

数据集与生态

项目主要价值机体 / 采集骨架中的位置
RoboNet / BridgeData早期多任务、多环境真实操作数据多机构或多场景遥操作跨场景预训练的前史
Open X-Embodiment把多机构数据映射到标准格式，论文报告 22 种机器人、527 项技能[14]21 个机构的数据集合跨机体数据混合与 RT-X
DROID分布式真实场景采集，论文报告 76k 演示、350 小时、564 个场景[21]统一 Franka 硬件设置和多人采集场景与采集者多样性
ALOHA / ACT双臂精细操作、低成本 leader-follower 和 action chunking[20]双臂遥操作硬件、数据和策略协同设计
AgiBot World企业级具身数据与工具生态厂商多产品族规模随版本变化，引用官方版本而非二手数字[30]

格式与契约

RLDS 采用 episode 包含 step 的顺序决策模型，曾是 Open X-Embodiment 的重要格式基础；其官方仓库已于 2025-11-29 归档，应视为有影响力的标准而非持续更新的默认实现。[35] LeRobotDataset v3 把低维高频信号存入 Parquet，把多相机视频存入 MP4，并用 JSON / Parquet 元数据维护 schema、统计量和 episode 边界。[34]

采集质量清单

  • 统一时钟、硬件时间戳和控制周期
  • 相机内外参、机器人基座和工具坐标系
  • 丢帧、编码延迟和状态插值策略
  • 动作是绝对、增量、关节还是末端命令
  • episode 边界、reset 和终止原因
  • 成功、失败、干预和恢复标签
  • 原始数据、派生数据和归一化版本
  • 隐私、人员入镜、许可和可删除性

9. 任务编排

任务编排位于技能和控制器之上，负责把目标拆成可执行步骤，检查前置条件，调度技能，监控结果，并在失败后恢复或重规划。它不替代低层控制，也不等于单次自然语言规划。

主要范式

范式表达能力优势主要风险
有限状态机显式状态与转移简单、可审计、实时状态和异常组合膨胀
行为树序列、选择、并行、装饰节点模块化、反应式、易监控；BehaviorTree.CPP 支持异步动作和 ROS 2[36]共享状态和复杂恢复仍需设计
PDDL / HTN符号动作、前置条件、效果或任务层级可搜索和验证世界状态与技能效果的建模成本
TAMP / MoveIt Task Constructor任务离散决策和连续运动约束联合把复杂任务分成 generator、propagator、connector stages[37]组合搜索和接触可行性
技能图 / Options可重用闭环技能及其终止条件连接学习策略与长时程任务技能接口和分布外失败
LLM / VLM 规划器自然语言分解、代码或技能选择语义泛化和快速组合幻觉、状态不一致和不可执行计划

最小闭环

  1. 解析目标并绑定对象、地点和约束。
  2. 从感知与世界状态中建立可查询的 grounded state。
  3. 选择技能或分解子任务，并检查前置条件。
  4. 通过 typed skill API 下发目标、超时和安全边界。
  5. 监控执行反馈、成功判据和环境变化。
  6. 失败时重试、换技能、回退到安全状态、重规划或请求人工。
  7. 记录结果，用于评测、数据回流和技能模型更新。

语言模型进入编排层

  • SayCan：用语言模型评估语义相关性，用技能价值函数约束可执行性。[22]
  • Code as Policies：让代码模型组合感知和控制 API，生成可执行策略程序。[23]
  • Inner Monologue：把成功检测、场景描述和人类反馈重新送回规划上下文。[43]

安全约束：LLM 输出必须通过技能白名单、类型检查、前置条件 / 效果、几何与动力学可行性、安全门和超时机制。自然语言合理不代表机器人可执行。

系统评测项

  • 任务完成率和平均重规划次数
  • 失败检测延迟与误判
  • 技能覆盖、前置条件和效果准确度
  • 计划可执行率与几何可行率
  • 人工接管率和安全违规
  • 完整事件日志和可回放性

下一步如何扩写

后续每个主题都可以拆成独立页面，并使用同一个模板，以便逐步走向结构化而不是堆论文：

  1. 定义与边界：对象是什么，不是什么。
  2. 对象与接口：输入、输出、状态、坐标系、时间尺度。
  3. 基本方程：最小数学结构和核心假设。
  4. 算法族：按共同结构分类，而非按实验室或产品名分类。
  5. 实现栈：硬件、实时系统、仿真器、SDK 与数据契约。
  6. 基准与数据：评测拆分、指标和不可比条件。
  7. 失败模式：奇异、接触、分布外、延迟、模型误差和安全。
  8. 支柱论文：经典定义、关键转折和当前开放实现。
  9. 开放问题：可被实验或理论工作推进的具体问题。
